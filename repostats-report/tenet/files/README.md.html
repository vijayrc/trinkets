1# Tenet
2*A tenet is a principle, belief, or doctrine generally held to be true, especially one shared by members of an organization, profession, or movement*
3A modular AI agent framework for interacting with the [Mambu](https://www.mambu.com/) banking API, built on [Strands Agents](https://github.com/strands-agents/strands-agents).
4
5Tenet uses a plugin-based architecture to give LLM agents the ability to call Mambu's REST API through natural language.
6Ask the agent to create a client, open a deposit account, disburse a loan, or query the general ledger -- it handles authentication, API calls, and response parsing automatically.
7

47## Request Flow
48
49```mermaid
50sequenceDiagram
51 participant User
52 participant Agent as Strands Agent
53 participant Plugin as Plugin (e.g. DepositPlugin)
54 participant Mambu as Mambu API v2
55
56 User->>Agent: Natural language request
57 Agent->>Agent: Parse intent and select tool
58 Agent->>Plugin: Invoke tool (e.g. call_create_deposit_account)
59 Plugin->>Plugin: BeforeToolCallEvent hook (log)
60 Plugin->>Mambu: HTTP request with Basic Auth + v2 headers
61 Mambu-->>Plugin: JSON response
62 Plugin->>Plugin: AfterToolCallEvent hook (log)
63 Plugin-->>Agent: Return response
64 Agent-->>User: Formatted answer
65```

67## Scene-Based Execution
68
69Tenet supports running multi-step workflows from text files called **scenes**. Each `.txt` file in the scenes directory contains a natural language prompt that is executed sequentially by the agent.
70
71```mermaid
72graph LR
73 ScenesDir[scenes/] --> F1[scene1.txt]
74 ScenesDir --> F2[scene2.txt]
75 F1 --> Agent[Strands Agent]
76 F2 --> Agent
77 Agent --> Mambu[Mambu API v2]
78```
79
80Example scene (`scenes/scene1-create-deposit-account.txt`):
81```
821 Create a Client with firstName Vijay and lastName Chak
832 Make a General Ledger Account
84```

109## Plugins
110
111Each plugin extends `strands.plugins.Plugin` and provides **hooks** (lifecycle callbacks) and **tools** (callable functions the agent can invoke). All plugins authenticate via HTTP Basic Auth against the Mambu v2 API.
112
113### DepositPlugin
114
115Covers deposit accounts, deposit products, and deposit transactions.
116
117| Tool | Mambu API | Description |
118|---|---|---|
119| `call_get_account_details` | Deposits / Get by ID | Fetch deposit account details |
120| `call_create_deposit_account` | Deposits / Create | Create a new deposit account |
121| `call_create_authorization_hold` | Deposits / Auth Hold | Place an authorization hold |
122| `call_get_deposit_product` | Deposit Products / Get by ID | Fetch a deposit product |
123| `call_create_deposit_product` | Deposit Products / Create | Create a deposit product |
124| `call_get_transaction_by_id` | Deposit Transactions / Get by ID | Fetch a transaction |
125| `call_make_deposit_transaction` | Deposit Transactions / Deposit | Make a deposit |
126| `call_make_withdrawal_transaction` | Deposit Transactions / Withdrawal | Make a withdrawal |
127| `call_make_transfer_transaction` | Deposit Transactions / Transfer | Transfer between accounts |
128| `call_apply_fee` | Deposit Transactions / Apply Fee | Apply a predefined fee |
129| `call_adjust_transaction` | Deposit Transactions / Adjust | Adjust a transaction |
130
131### LendingPlugin
132
133Covers loan accounts, loan products, and loan transactions.
134
135| Tool | Mambu API | Description |
136|---|---|---|
137| `call_get_loan_product` | Loan Products / Get by ID | Fetch a loan product |
138| `call_create_loan_product` | Loan Products / Create | Create a loan product |
139| `call_get_loan_account` | Loans / Get by ID | Fetch a loan account |
140| `call_create_loan_account` | Loans / Create | Create a loan account |
141| `call_make_disbursement` | Loan Transactions / Disburse | Disburse loan funds |
142| `call_make_repayment` | Loan Transactions / Repay | Make a loan repayment |
143| `call_apply_fee` | Loan Transactions / Apply Fee | Apply a predefined fee |
144
145### LedgerPlugin
146
147Covers general ledger accounts.
148
149| Tool | Mambu API | Description |
150|---|---|---|
151| `call_get_all_gl_accounts` | GL Accounts / Get All | List all GL accounts |
152| `call_get_gl_account` | GL Accounts / Get by ID | Fetch a GL account |
153| `call_create_gl_account` | GL Accounts / Create | Create a GL account |
154
155### OrgPlugin
156
157Covers organisation setup, clients, branches, centres, and transaction channels.
158
159| Tool | Mambu API | Description |
160|---|---|---|
161| `call_get_organization_setup` | Organisation / Get Setup | Fetch org configuration |
162| `call_get_transaction_channel` | Transaction Channels / Get by ID | Fetch a channel |
163| `call_create_transaction_channel` | Transaction Channels / Create | Create a channel |
164| `call_update_transaction_channel` | Transaction Channels / Update | Update a channel |
165| `call_get_centre` | Centres / Get by ID | Fetch a centre |
166| `call_get_client` | Clients / Get by ID | Fetch a client |
167| `call_create_client` | Clients / Create | Create a client |
168| `call_get_branch` | Branches / Get by ID | Fetch a branch |
169| `call_create_branch` | Branches / Create | Create a branch |

171## Getting Started
172
173### Prerequisites
174
175- Python >= 3.14
176- [uv](https://docs.astral.sh/uv/) (recommended package manager)
177- A Mambu tenant with API credentials
178
179### Installation
180
181```bash
182uv sync
183```
184
185### Configuration
186
187Set the following environment variables:
188
189```bash
190export MAMBU_TENANT="your-tenant"
191export MAMBU_USER="your-api-user"
192export MAMBU_PASSWORD="your-api-password"
193export TENET_SCENES_DIR="./scenes"
194```
195
196Or create a `.env` file (uncomment the `model_config` line in `src/tenet/models/config.py` to enable).
197
198### Running
199
200Run scenes from a directory:
201
202```bash
203uv run python src/tenet/agents/simple_agent.py
204```
205
206Or use the agent programmatically:
207
208```python
209from strands import Agent
210from tenet.plugins.deposit_plugin import DepositPlugin
211from tenet.plugins.lending_plugin import LendingPlugin
212from tenet.plugins.ledger_plugin import LedgerPlugin
213from tenet.plugins.org_plugin import OrgPlugin
214from tenet.models.config import AppSettings
215
216settings = AppSettings()
217agent = Agent(
218 plugins=[DepositPlugin(), LedgerPlugin(), LendingPlugin(), OrgPlugin()],
219 state={
220 "tenant": str(settings.mambu_tenant),
221 "user": str(settings.mambu_user),
222 "password": str(settings.mambu_password),
223 },
224)
225
226agent("Create a client named John Doe and open a savings account for them")
227```
228

230
